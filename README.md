# JDC Innovations & Solutions Website

A responsive, single-page business website for JDC Innovations & Solutions.

## Files
- `index.html` — website content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year
- `README.md` — publishing instructions

## Important before publishing
1. Replace `info@jdcinnovationsandsolutions.com` in `index.html` with the business email address you want to receive inquiries.
2. Review the service descriptions and contact information.
3. If you do not own the domain `jdcinnovationsandsolutions.com`, do not advertise that email address until it is configured.

## Free hosting: GitHub Pages
GitHub Pages can host static HTML/CSS/JavaScript sites at no separate hosting charge when using a public repository with GitHub Free.

### Quick setup
1. Create a free GitHub account at https://github.com/
2. Create a new **public** repository named `jdc-innovations-solutions`.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder.
4. Open the repository's **Settings → Pages**.
5. Under the publishing/source option, select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
6. Save.
7. GitHub will provide the live `github.io` website address. It can take several minutes to publish.

You can later connect a custom domain if you purchase one.

## Alternative free host
Netlify also offers a $0/month Free plan and can deploy static sites. You can drag the website folder into Netlify's deployment interface or connect a Git repository.

## Contact form note
The contact form uses FormSubmit as a simple email-forwarding service. The first submission may require email confirmation. For a production website, review the form provider's current terms and privacy practices and replace it with the business's preferred form/email solution if needed.
